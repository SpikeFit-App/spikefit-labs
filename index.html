Acoustic Jump Sensor

Acoustic State Machine

A hands-free jump height estimator that monitors dynamic noise levels on hardwood courts. Filters floor shoe squeaks and thuds through a double-threshold air gap silence analyzer to clock true takeoff and landing timestamps.

Web Audio API • Mic Dependent

Workload & Readiness Key

An integrated, localized workload manager tracking your Acute:Chronic Workload Ratio (ACWR). Helps jump athletes prevent patellar tendinopathy (Jumper's Knee) by dynamically scaling training load in localStorage.
